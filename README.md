# log-level
log level defines the severity of a log message and controls which messages an application displays or records. It helps developers monitor application activities, identify errors, and debug problems.

1. DEBUG

-Provides detailed information for debugging and troubleshooting.

2. INFO

-Reports normal application activities, such as application startup or successful task execution.

3. WARNING

-Indicates an unexpected situation that may require attention but does not necessarily stop the application.

4. ERROR

-Indicates that an operation has failed.

5. CRITICAL

-Indicates a very serious problem that may prevent the application from continuing normally.
